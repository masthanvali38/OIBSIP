# Sales Prediction Using Python

## Project Overview

This project aims to predict product sales based on advertising expenditure using machine learning regression models.

## Dataset

The dataset, `Advertising.csv`, contains advertising expenditure for:
- TV
- Radio
- Newspaper

The target variable is `sales`.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Workflow

1. Load and explore the dataset.
2. Check missing values and calculate descriptive statistics.
3. Perform exploratory data analysis (EDA).
4. Visualize relationships using scatter plots, a pairplot, and a correlation heatmap.
5. Split the dataset into training and testing sets.
6. Train regression models.
7. Evaluate model performance using MAE, RMSE, and R².
8. Compare model performance.
9. Analyze residuals and advertising channel coefficients.

## Machine Learning Models

- Linear Regression
- Polynomial Regression
- Random Forest Regression

## Evaluation Metrics

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R-squared Score (R²)

## How to Run

1. Install Python and Jupyter Notebook.
2. Install the required libraries: `pandas`, `numpy`, `matplotlib`, `seaborn`, and `scikit-learn`.
3. Keep `Advertising.csv` and `Sales_Prediction.ipynb` in the same folder.
4. Open the notebook in Jupyter Notebook.
5. Run the notebook cells in order.

## Conclusion

This project demonstrates data exploration, visualization, regression modeling, model evaluation, and interpretation of advertising channel relationships with sales. Linear Regression and Polynomial Regression have been implemented; Random Forest Regression will be added after resolving the environment issue.
