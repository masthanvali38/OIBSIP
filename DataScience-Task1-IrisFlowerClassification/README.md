# Task 1 – Iris Flower Classification

## OASIS INFOBYTE Data Science Internship

### Objective
To train Machine Learning classification models to identify Iris flower species using physical measurements.

### Dataset
The Iris dataset is loaded directly from `sklearn.datasets.load_iris()`.

### Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

### Project Workflow
1. Load the Iris dataset
2. Perform Exploratory Data Analysis
3. Visualize feature distributions
4. Discuss feature selection
5. Split data into training and testing sets
6. Train classification models
7. Evaluate model performance
8. Identify the best-performing model
9. Predict Iris flower species

### Notebook
`iris_classification.ipynb`

### Conclusion
The project compares classification models and identifies the best-performing model based on evaluation metrics.
