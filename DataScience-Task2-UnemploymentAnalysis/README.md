# Unemployment Analysis with Python

## OASIS INFOBYTE – Data Science Internship

### 1. Project Overview

Unemployment is an important economic indicator that reflects the employment situation of a country.

This project focuses on analyzing unemployment data in India using Python. The main objective is to explore unemployment trends across different regions and understand the impact of the COVID-19 pandemic on unemployment rates.

### 2. Project Objectives

- Analyze unemployment rates across different Indian states and regions.
- Identify monthly unemployment trends.
- Compare unemployment rates across different regions.
- Identify the top 10 regions with the highest average unemployment rates.
- Analyze relationships between unemployment, employment, and labour participation.
- Compare unemployment rates before and after COVID-19.

### 3. Dataset Information

- **Dataset Name:** Unemployment in India
- **File Name:** Unemployment in India.csv
- **Source:** Kaggle
- **Format:** CSV

**Dataset Columns:**
- Region
- Date
- Frequency
- Estimated Unemployment Rate (%)
- Estimated Employed
- Estimated Labour Participation Rate (%)
- Area

### 4. Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

### 5. Project Workflow

1. Import required Python libraries.
2. Load the unemployment dataset.
3. Inspect dataset shape, columns, data types, and missing values.
4. Perform data cleaning and preprocessing.
5. Conduct Exploratory Data Analysis (EDA).
6. Calculate region-wise average unemployment rates.
7. Analyze month-wise unemployment trends.
8. Compare unemployment trends across three regions.
9. Identify the top 10 regions with the highest average unemployment rates.
10. Generate a correlation heatmap.
11. Compare pre-COVID and post-COVID unemployment rates.
12. Summarize findings and conclusions.

### 6. Data Analysis and Visualizations

The project includes the following analysis:

- Region-wise average unemployment rate.
- Monthly unemployment trend.
- Unemployment comparison across three regions.
- Top 10 regions with the highest unemployment rates.
- Correlation between unemployment, employment, and labour participation indicators.
- Pre-COVID vs Post-COVID unemployment comparison.

### 7. Key Findings

The analysis aims to identify regional differences, monthly unemployment trends, and changes in unemployment rates between the pre-COVID and post-COVID periods.

Detailed findings will be updated after completing the analysis.

### 8. Conclusion

This project uses Python-based Exploratory Data Analysis and visualization techniques to understand unemployment patterns in India.

It helps identify regional unemployment differences, monthly variations, and changes in unemployment rates during the COVID-19 period.
